# pi-notify

ORGM Pi notify package extracted from `pi-harness`.

## Install

```bash
pi install git:github.com/osmargm1202/pi-notify
```

This package is also loaded by the ORGM bundle:

```bash
pi install git:github.com/osmargm1202/pi-harness
```

## Owns

- `extensions/notify.ts`

## Development

```bash
npm install
npm test
npm run pack:check
```
